## Edge TTS 0.2.0

把文字转成语音的 Windows 桌面工具。Telegram 风格的聊天界面：左边是音色，中间是对话，你发文本，它回语音消息。

### 下载与安装
- 下载 **`Edge TTS_0.2.0_x64-setup.exe`**，双击安装（安装给当前用户，不需要管理员权限）。
- 系统要求：Windows 10 / 11（64 位），需要联网。
- ⚠️ **安装包没有代码签名**，Windows 会弹出蓝色的“Windows 已保护你的电脑”。点 **“更多信息” → “仍要运行”** 即可。
- 想核对文件完整性：对比 `SHA256SUMS.txt`（`Get-FileHash 文件 -Algorithm SHA256`）。

### 功能
- **两种引擎**：Edge 在线语音（免费、无需账号）和 Azure AI Speech（自备密钥，音色多，支持情感风格）
- 长文本自动分段，章节 / 多角色合成，**字幕导出（SRT / VTT）**，批量导出 ZIP
- 导入 TXT / Markdown / DOCX，参数预设，音色收藏与试听
- Azure 额度提醒（本机估算）、完成时的系统通知
- 键盘操作（Esc、↑↓、Ctrl+B），可折叠、可拖动调宽的音色栏
- 一键导出日志，方便排查问题

### 请注意
- **Edge 在线语音走的是微软的非官方接口**，可能随时变化或失效。Azure 是官方接口，更稳定。
- **你输入的文字会发送给微软的服务器**合成语音；本软件没有任何统计或遥测。
- Azure 的字幕时间按句子字数估算，可能与语音差零点几秒；Edge 引擎的字幕是精确的。
- 已在 Windows 11 上测试（含安装、卸载、全流程）。其他系统版本、杀毒软件环境下的表现尚未充分验证；遇到问题请[提交 Issue](../../issues) 并附上导出的日志。
