# 发布指南（给发布者）

## 一键发布

```powershell
.\scripts\release.ps1 -Contact "你的邮箱或网址"
```

它依次做：版本一致性检查 → 后端 lint 与测试 → 后端打包与冒烟 → 确认不含 GPL 的 mutagen → 生成第三方许可声明 → 前端检查与单元测试 → 桌面安装包 → 端到端测试 → 汇总到 `release\vX.Y.Z\`（安装包、`SHA256SUMS.txt`、《第三方许可声明.txt》、《用户指南.md》）。

- 本地试跑：加 `-AllowPlaceholder -SkipE2E`。
- 改版本号：`node scripts/version.mjs set 0.3.0`（一次改全部位置；不带参数是检查是否一致）。
- 运行端到端测试前请关闭正在使用的 Edge TTS。

## 发出去之前必须处理的事

### 1. 许可合规（必须）

| 组件 | 许可 | 你要做的 |
| --- | --- | --- |
| FFmpeg（随包的 ffmpeg.exe） | GPL-3.0（构建启用了 `--enable-gpl`） | 以独立进程调用，不会让你的代码受 GPL 约束；但分发它本身必须提供许可全文和**获取源码的途径** |
| edge-tts | LGPL-3.0 | 必须附许可全文，并让用户能**替换该库后重新运行**——通常意味着要能提供你项目的源码/构建说明 |
| certifi 等 | MPL-2.0 | 附许可文本即可 |
| 其余（MIT/Apache/BSD 等） | 宽松 | 保留版权与许可声明（已由脚本自动汇总） |

**所以你需要决定并填写**：
- 你自己这个软件用什么许可？（开源还是闭源。如果打算闭源，要重点确认 edge-tts 的 LGPL 能否满足：最稳妥的做法是公开后端源码或提供构建与替换说明。）
- 联系方式：`-Contact` 会写进《第三方许可声明》，作为索取 FFmpeg 和 edge-tts 源码的途径。不填的话脚本会拒绝正式发布。

> mutagen（GPL-2.0+）已从程序中移除，改用自带的 MP3 时长解析（`backend/src/edge_tts_backend/mp3.py`）。发布脚本和测试都会检查它没有回来。

以上是技术层面的整理，**不是法律意见**。如果要商业分发，请让懂行的人看一下。

### 2. “Edge 在线语音”引擎的风险（必须知道）

该引擎通过 `edge-tts` 库访问微软 Edge 浏览器“朗读”功能所用的服务。这是**非官方、未受微软支持的接口**：
- 微软可以随时改变或限制它，届时该引擎会失效，需要升级 `edge-tts` 并重新发版。
- 把它分发给更多人，意味着你的产品依赖一个没有服务保证、也可能不符合微软服务条款的接口。
- **Azure 引擎走的是官方接口**，是合规、稳定的路线。如果要面向很多用户，建议把 Azure 作为主推，或让用户自备密钥。

用户指南里已如实说明了这一点。

### 3. 代码签名（强烈建议，非必须）

没有签名时，用户安装会看到 SmartScreen 的蓝色警告，部分杀毒软件也更容易误报（尤其是 PyInstaller 打包的程序）。选项：

| 方式 | 说明 |
| --- | --- |
| 购买代码签名证书（OV/EV） | 传统做法，每年几百到上千元。EV 证书可立即消除 SmartScreen 警告，OV 需要积累信誉。 |
| Azure Trusted Signing | 微软的托管签名服务，按月计费，门槛较低，对个人和小团队友好（需通过身份验证）。 |
| 开源项目的免费签名 | 如 SignPath Foundation 面向开源项目提供免费签名（需公开源码）。 |

拿到证书并装入当前用户证书库后，设置环境变量再运行发布脚本即可自动签名：

```powershell
$env:EDGE_TTS_SIGN_THUMBPRINT = "证书指纹"
.\scripts\release.ps1 -Contact "..."
```

脚本结尾会打印签名状态。使用 Trusted Signing 等需要自定义命令的方式时，改用 Tauri 的 `bundle.windows.signCommand` 配置。

### 4. 自动更新（可选，需要你提供两样东西）

目前没有自动更新，用户需要自己下载新安装包。要加自动更新，需要：
1. **更新包托管位置**：例如 GitHub Releases，或你自己的静态网站，用来放安装包和一个 `latest.json`。
2. **更新签名密钥**：用 `npx tauri signer generate` 生成密钥对。**私钥必须妥善保管**，丢了就没法再给已安装的用户推送更新。

之后集成 `tauri-plugin-updater`，在“关于”里加“检查更新”，并在 CSP 的 `connect-src` 里加入托管域名。这些依赖你的托管选择，所以我没有预先写死。

### 5. 杀毒软件误报

PyInstaller 单文件程序偶尔会被杀毒软件误报。缓解办法：签名；把 `build.ps1` 改成目录模式（`--onedir`）；向主流厂商提交误报申诉。无法在本机验证各家杀毒软件的反应。

## 发布物检查清单

- [ ] `release.ps1` 全部通过（含端到端）
- [ ] 《第三方许可声明》里的联系方式已填写
- [ ] 已决定本软件自己的许可
- [ ] （建议）安装包已签名，脚本最后一行显示签名状态为 `Valid`
- [ ] 在一台**干净的 Windows**（没有开发环境，最好是虚拟机）上安装并完整试用一遍
- [ ] 发布页同时提供 `SHA256SUMS.txt` 和《用户指南》

## 没有覆盖到的

- 干净机器、不同杀毒软件、不同 Windows 版本和系统缩放比例下的表现。
- 真实的 Azure 服务（测试用的是本地模拟服务器）。
- 安装包的升级覆盖安装流程（目前只测了全新安装与卸载）。
