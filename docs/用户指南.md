# Edge TTS 用户指南

把文字转成语音的 Windows 桌面工具。支持长文本、章节和多角色、字幕导出，可选免费的 Edge 在线语音，或接入自己的 Azure 账号。

## 安装

**系统要求**：Windows 10 或 Windows 11（64 位），需要联网（语音由在线服务合成）。

1. 双击 `Edge TTS_x.y.z_x64-setup.exe`。默认安装给当前用户，**不需要管理员权限**。
2. **看到蓝色的“Windows 已保护你的电脑”？** 这是因为安装包没有购买代码签名证书，Windows 不认识发布者，并不代表有病毒。点 **“更多信息” → “仍要运行”** 即可。
3. 想确认文件没被改动过，对比 `SHA256SUMS.txt` 里的值：在 PowerShell 里运行 `Get-FileHash 安装包路径 -Algorithm SHA256`，结果应与文件里一致。
4. 如果杀毒软件拦截或误报，请从来源重新下载并对照上面的校验值，确认无误后加入信任。
5. 界面由系统的 WebView2 渲染。Windows 11 自带；缺少时安装程序会引导你从微软下载。

## 开始使用

1. 左侧选一个**音色**（可搜索，点星标收藏，点小喇叭试听）。
2. 在底部输入文字，按 **Ctrl+Enter**（或点发送键）。
3. 稍等片刻，对话里出现一条**语音消息**：点播放，波形可点击跳转，右下角可切换 1×/1.5×/2× 倍速。
4. 消息下方的按钮可以保存音频（MP3）、导出字幕（SRT/VTT）、重新编辑、改标题、删除。

**常用功能**

| 想做的事 | 怎么做 |
| --- | --- |
| 导入文档 | 点输入框左边的回形针，或把 TXT / Markdown / DOCX 拖进窗口 |
| 一篇文字分成多个文件 | 输入框上方切到“分段独立文件” |
| 多个章节或多个角色 | 切到“章节 / 多角色”，每段可单独选音色和风格 |
| 批量导出 | 点右上角的“多选”图标，勾选后导出 ZIP |
| 调语速、音量、音调、字幕 | 点右上角的“信息”图标，打开右侧的“合成设置” |
| 保存常用参数 | 在“参数预设”里命名保存，之后一键套用 |
| 收起音色栏 | 点栏顶的图标，或按 **Ctrl+B**；也可以拖动它的右边缘调整宽度 |

## 两种语音引擎

| | Edge 在线语音 | Azure AI Speech |
| --- | --- | --- |
| 费用 | 免费，无需账号 | 需要你自己的 Azure 账号和密钥；每月有免费额度，超出收费 |
| 音色 | 较少（中文约 14 个） | 更多，且有多种说话风格（开朗、新闻播报、客服等） |
| 字幕 | 与语音逐句精确对齐 | 按句子字数估算，可能差零点几秒 |
| 稳定性 | 使用的是微软的**非官方**接口，**可能随时变化或失效** | 官方接口，稳定 |

**配置 Azure**：在 [Azure 门户](https://portal.azure.com) 创建 **Speech（语音）** 资源，定价层选 **Free F0**；在资源的“密钥和终结点”页复制 **KEY 1** 和**区域**（如 `eastus`）。回到应用，打开右侧“合成设置”→“语音引擎”，填入区域和密钥，点“保存并测试”。
面板里会显示本月用量；快用完时会提醒你。用量是本机估算，准确数字以 Azure 门户为准。

## 隐私与数据

- **你输入的文字会被发送到微软的服务器**合成语音（Edge 引擎发给 Edge 的朗读服务，Azure 引擎发给你自己的 Azure 资源）。请不要输入你不愿意发给微软的内容。
- 本软件**不含任何统计或遥测**，不会把你的内容发给其他任何地方。
- **Azure 密钥**用你的 Windows 账户加密后保存在本机，只有当前 Windows 用户能解开；界面只显示末 4 位。
- **日志**只记录事件和错误类别，不含你的文字和密钥。
- 数据保存位置：
  - 历史记录、生成的音频、缓存、日志：`%LOCALAPPDATA%\EdgeTTSDesktop`
  - 界面设置（主题、侧栏宽度）：`%LOCALAPPDATA%\com.edgettsdesktop.app`
  - 窗口位置：`%APPDATA%\com.edgettsdesktop.app`

## 常见问题

**音色列表一直加载不出来？**
Edge 引擎需要访问微软服务，请检查网络和代理。点侧栏里的“重试”；网络恢复后会自动使用。

**Azure 提示“密钥无效或与区域不匹配”？**
最常见的原因是区域填错。区域要和 Azure 资源页显示的位置**完全一致**，用小写英文代码（`eastus`，不是 “East US”）。

**提示额度用完或被限流？**
免费额度每月重置。可以去 Azure 门户确认用量，或暂时切回 Edge 引擎。

**合成很慢或失败？**
长文本会自动分段合成并在失败时重试；网络不稳定时可点消息下方的“重试”。

**怎么卸载？**
“设置 → 应用”里卸载。卸载**不会删除**你的历史和音频，想彻底清除请手动删除上面列出的三个文件夹。

**遇到问题怎么反馈？**
打开右侧“合成设置”→“关于与诊断”→“导出日志”，把日志文件发给开发者。日志里不含你的文字和密钥。
