# 端到端冒烟测试

驱动**打包后的桌面应用**走完主要流程：Azure 配置、引擎切换、中文音色名、说话风格、合成与播放、用量统计、键盘操作、侧栏折叠、日志与诊断、密钥不落明文。

特点：

- **完全离线**：用 `fake_azure.py` 模拟 Azure 服务，不需要真实密钥，也不消耗额度。
- **不碰你的数据**：后端数据目录和 WebView 浏览器存储（`WEBVIEW2_USER_DATA_FOLDER`）都指向临时目录；窗口状态文件无法重定向，会先备份、结束后还原。
- 注意：Tauri 的应用数据目录由系统接口决定，**不会**跟随 `LOCALAPPDATA` 环境变量，所以隔离必须靠上面两个变量。
- **自带清理**：无论成功失败都会关闭应用和假服务器，并删除临时目录。

## 运行

```powershell
# 前提：已构建应用，且 backend 下执行过 uv sync
cd desktop
npx tauri build
npm run e2e
```

运行前请先关闭正在使用的 Edge TTS（单实例机制会让测试接管你的窗口，脚本检测到会直接退出）。

输出示例：每项检查一行 `✓` / `✗`，最后汇总；有失败时退出码为 1。

## 它没有覆盖的

- 真实的 Edge 在线语音和真实的 Azure 服务（需要网络或密钥）。
- 系统原生的“另存为”对话框和系统通知的实际弹出。
- 干净 Windows 机器上的安装。

## 安装测试

```powershell
npm run e2e:install
```

把安装包**静默安装到临时目录**，用安装出来的程序跑一遍上面的端到端测试，再静默卸载，检查程序文件、“应用”列表条目、开始菜单快捷方式是否清理干净。这是在“没有开发环境的机器”上的体验的近似。

- 如果机器上已安装了正式版的 Edge TTS，脚本会直接中止，避免影响它。
- **请在普通的 PowerShell 或 cmd 里运行**。在某些受限/沙箱化的终端里，安装程序对注册表的写入会被隔离，“已注册到应用列表”会误报失败（安装包本身没有问题）。
